# ShellGATE
Bastion SSH
SHELLGATE

SHELLGATE est un projet open source visant à proposer une alternative légère et accessible aux solutions de bastion d'administration existantes.

Le projet est né d'un constat simple : certaines solutions professionnelles, comme Wallix, sont particulièrement complètes mais peuvent être surdimensionnées ou difficilement accessibles dans certains contextes. À l'inverse, des solutions comme Apache Guacamole ou Teleport répondent à une partie du besoin, mais ne correspondent pas nécessairement à tous les usages.

L'objectif de SHELLGATE est donc de proposer une solution intermédiaire, centrée dans un premier temps sur l'administration sécurisée des infrastructures, tout en restant :

open source ;
légère ;
compréhensible ;
facilement déployable ;
extensible ;
adaptée aux environnements de laboratoire, d'apprentissage et aux petites infrastructures.

SHELLGATE est avant tout un projet développé dans le cadre de l'apprentissage.

Le projet est développé par un étudiant ayant des connaissances en administration système, notamment Linux, Docker et Python.

L'objectif est également de permettre à d'autres étudiants de découvrir et d'approfondir différents domaines :

développement Python ;
développement backend ;
conception d'API ;
bases de données ;
architecture logicielle ;
administration système ;
réseaux ;
cybersécurité ;
DevOps ;
tests et intégration continue.

Le projet se veut donc également pédagogique.

L'idée est de construire progressivement une application complète, en documentant les choix techniques et les difficultés rencontrées afin que d'autres personnes puissent comprendre le fonctionnement du projet et, pourquoi pas, contribuer à son développement.
